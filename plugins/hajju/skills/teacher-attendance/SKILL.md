# Teacher attendance with Hajju

Use the connected Hajju MCP server for teacher attendance requests. The teacher authorizes access through Smart Madrasa; never ask for credentials in chat.

For a class-specific request, first list the teacher's assigned classes and use an ID returned by the server. If a class name is ambiguous, ask the teacher which one they mean. Use the server's attendance and report tools for the requested day or date range; paginate reports when needed.

Before recording attendance, retrieve the existing marks for the class and date. Show the exact students, statuses, and existing marks that would change. Get approval for those specific changes before submitting them. Only replace an existing mark when the teacher explicitly approves that replacement. Attendance updates may notify parents.
